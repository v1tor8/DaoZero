# DaoZero

Distributes real-time data processing across decentralized networks, enabling autonomous decision-making on a decentralized Dao platform.

With DaoZero, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DaoZero.git`
2. `cd DaoZero`
3. Install in editable mode: `pip install -e .`

## Configuration

DaoZero is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
